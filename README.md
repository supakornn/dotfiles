# dotfiles

Personal macOS setup managed by [Chezmoi](https://www.chezmoi.io/), [Homebrew](https://brew.sh/), and [Mise](https://mise.jdx.dev/).

```sh
git clone https://github.com/supakornn/dotfiles.git ~/Documents/dotfiles
cd ~/Documents/dotfiles
./bootstrap.sh
```

- `Brewfile`: apps and system tools
- `~/.config/mise/config.toml`: developer tools
- `~/.gitconfig.local`: local Git identity
